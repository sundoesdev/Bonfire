# Testing Notes

### Below are my thoughts on future roadmap ideas that will be implemented after a thorough testing period:

1. 06/05/2026 ALL buttons, must be the same height and relative width (depends on word wrap), cannot have black backgrounds, and must be attention grabbing to the human eye. I feel like the drop down menus could be smaller to be of similar size to most of the buttons. And then specifically the "Rename" button in the decks view on settings should not have black background, should be larger, but still be a different color than the other more important buttons. I think what I'm trying to describe is the overall programs CRUD (and the buttons and interactions that control the CRUD) need a UI syncronism in terms of color that assume what kind of impact they will have (for example, red meaning dangerous), a size that's synconized
2. 06/05/2026 The UI definetly needs a less aggressive feel, there's a lot of friction: I either don't know what half the settings do (poorly described), I either can't find or see those settings, and it feels like information overload (the current version of the software feels very intimidating). What I think would solve this is by giving the user less options when confronted with the most important UIs (less options, less drop downs, less descisions to make) and hiding those in settings. On top of this, cleaning up settings to be more presentable with plenty of describing text so the user isn't left clueless as to what something does or affects in the software, and how it affects it. On top of that, making buttons and drop downs follow a common theme and sizing parameter, both color wise, font sizes, and height width
3. 06/05/2026 I'm realizing I dislike the current "New Shard" UI, and I much rather prefer the Quick Capture instead. What I'd like to do there is actually remove the full-capture UI entirely, when clicking "New Shard" brings you to the current Quick Capture UI, re-name the Quick Capture UI to "Add New Shard", and then flesh out this UI with the rest of the contents. All that "Quick Capture" is currently missing, which is now becoming the new and only way to add shards, is Category, Familiarity, Source (URL or Book or whatever), and Description. I want to completely remove the "Review: " button, aka the "In Review Queue" options, as this is irrelevent to ask in the first place, because all cards are being added with the default asumption that they will be reviewed.
4. CRAM Mode; I don't want it to effect card stats at all, that's something I noticed when using it a few times. For example if I choose a deck, time limit, max cards, and cram mode, studying that deck should not effect the SM-2 or FSRS algorithm at all. But, it can still adjust the heatmap, the % retention rate graph, the streak counter, and other data counters. So for example, if I'm supposed to study cards ABC tomorrow, and I decide to study them using CRAM Mode today, it should not effect the SM-2 algorithm predicting that I still need to study ABC tomorrow, but you can still update the heatmap and other stats, counting that as "I studied today" and "how many things did I do?" on the relevent charts and data points
